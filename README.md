# Audira — Landing Page (Next.js)

A polished landing page for the Audira Q20 premium headphones built with Next.js (App Router).

## Features

- Modern responsive landing page with a hero, product grid, and showcase sections.
- Authentication: sign up, login, logout, session restore, forgot & reset password.
- Device registration flow (warranty + points) stored in local JSON for development.
- Lightweight server routes under `src/app/api` (no external DB required by default).

## Quick start

Requirements: Node 18+ and npm

Install dependencies and run locally:

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

Build for production:

```bash
npm run build
npm run start
```

Linting:

```bash
npm run lint
```

## Notable files

- `src/components/Hero.tsx` — hero section; primary CTA is now above the fold (`heroPrimary` class in `src/components/Hero.module.css`).
- `src/components/ProfileDrawer.tsx` — sign in / sign up UI; includes forgot/reset flows.
- `src/app/api/auth/*` — authentication routes: `login`, `signup`, `logout`, `me`, `register-device`, `forgot-password`, `reset-password`.
- `src/lib/db.ts` — simple file-based user store (`src/data/users.json`).

## Local development notes

- User data is stored in `src/data/users.json`. This is intentionally simple for development and should be replaced by a proper database in production.
- Reset tokens are generated and stored temporarily in the user record and expire after 15 minutes.
- Sessions use an `audira_session` HTTP-only cookie generated by the in-repo JWT helper (`src/lib/auth.ts`).

## Testing the forgot/reset flow (dev only)

1. Open the profile drawer and choose "Forgot password".
2. Enter a valid email that exists in `src/data/users.json`.
3. The dev API currently returns the reset code in the response for testing; use it to finish the reset flow.

## Deploy

Vercel is recommended for Next.js apps. Connect the repository and use the default build command (`npm run build`) and output directory (handled by Next).
